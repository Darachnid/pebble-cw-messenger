# Android CW SMS Bridge — background notifications

Read the root [README](../README.md) for install, icons, and watch screenshots.

## Companion app

- **Main screen** — workflow, permissions, links to **Messages** and **User settings**
- **Messages** — recent SMS from notifications (no READ_SMS); reply via notification RemoteInput, watch Morse, or SMS compose fallback
- **User settings** — WPM, paddles, demo text, autoplay, push settings to watch

The APK uses notification access only; no PebbleKit JS ships in the watch PBW.
